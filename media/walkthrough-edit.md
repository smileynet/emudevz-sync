# Edit Your First File

In the Explorer, expand **EmuDevz Game Files** → **code** and open any `.js` file.

Make a change and save (`Ctrl+S`) — it syncs to the game instantly. Switch to the game window and your changes are already there!

**What you get in VS Code:**
- Full IntelliSense and autocomplete
- Multi-file editing with tabs
- Git version control on your code
- All your favorite extensions (Copilot, snippets, themes)
