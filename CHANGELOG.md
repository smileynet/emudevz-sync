# Changelog

## [0.1.0] - 2026-08-13

### Added
- Initial release
- Live bidirectional file sync between VS Code and EmuDevz
- FileSystemProvider (`emudevz://`) showing game files in Explorer
- CDP bridge with auto-reconnect (exponential backoff)
- File change detection via polling
- Status bar connection indicator
- Commands: Connect, Disconnect, Pull All, Push All
- Getting Started walkthrough
- Output channel for diagnostics
